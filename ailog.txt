 3. 如需要把 C 盘占用迁到 D 盘（供参考，AI 尚未执行）
--------------------------------------------------------------------------------
Maven 本地仓库（三种方式任选）
  方式一（推荐）：新建 C:\Users\lenovo\.m2\settings.xml，内容：
      <settings>
        <localRepository>D:/Environment/mvn.repo</localRepository>
      </settings>
      —— 之后本机所有 Maven（含 Maven Wrapper）统一改用 D 盘仓库，需重开终端生效
  方式二：设置用户环境变量 MAVEN_OPTS = -Dmaven.repo.local=D:/Environment/mvn.repo
  方式三：单次构建显式指定：
      D:\AAtmp\backend\mvnw.cmd -B -Dmaven.repo.local=D:/Environment/mvn.repo -DskipTests package
  Maven Wrapper 发行版目录（当前在 C 盘）：
      设置用户环境变量 MAVEN_USER_HOME = D:\Environment\m2（Maven Wrapper 3.2+ 支持）

npm 缓存（当前在 C 盘）
  npm config set cache D:\Environment\npm-cache          # 写入 C:\Users\lenovo\.npmrc，永久生效
  单次：npm install --cache D:\Environment\npm-cache
  环境变量：NPM_CONFIG_CACHE = D:\Environment\npm-cache
  迁移已有缓存：Move-Item 'C:\Users\lenovo\AppData\Local\npm-cache\*' 'D:\Environment\npm-cache\' -Force
